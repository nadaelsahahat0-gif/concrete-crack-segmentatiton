# Concrete Crack Segmentation Using Classical Image Processing

## Problem
Detect and segment cracks in concrete images using classical digital image processing techniques.

## Dataset
Concrete Crack Segmentation Dataset containing 445 matched RGB images and ground-truth binary masks.

## Objective
Generate binary masks that separate crack pixels from the concrete background.

## Evaluation Metric
Intersection over Union (IoU) will be the primary metric for evaluating segmentation performance.
